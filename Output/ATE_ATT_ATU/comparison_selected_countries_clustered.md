# ATE, ATT and derived ATU: selected countries, clustered folds

Coefficients are in probability units: **0.01 = one percentage point**. Standard errors are in parentheses. *** p<0.01, ** p<0.05, * p<0.1.

ATE averages over the analysis sample; ATT targets users of any treatment; ATU targets nonusers. The same target populations apply to each APOS contrast. ATU is derived, not separately fitted. Main results aggregate all cross-fitting repetitions using the project median rule. ATT-minus-ATU is derived in each repetition and then aggregated; it need not equal the difference of displayed medians. Median coefficients need not satisfy the exact ATE decomposition.
